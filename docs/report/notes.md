# Design notes

One line per design decision, for the Technical Report.

- 2026-10-08: Prettier pinned to 3.9.9 (latest stable at setup), run as `bunx prettier@3.9.9`.
- 2026-10-08: Acceptance criteria shared by a feature group in the plan (e.g. Boot sequence for F01–F02) are listed in each feature file of that group; phase exit criteria list each criterion once.
- 2026-10-08: Unit test files are named `tests/<module>_test.cc` (Google convention), e.g. `tests/clock_test.cc`.
- 2026-10-08: `.gitattributes` forces LF line endings (`* text=auto eol=lf`) so format checks give the same result on Windows and Unix checkouts.
- 2026-10-08: LLVM pinned to major version 23 (23.1.3, newest stable on winget at setup).
- 2026-10-08: clang-tidy `llvm-header-guard` dropped: it derives the expected guard from the absolute file path, so it cannot enforce `CSOPESY_SRC_<DIR>_<FILE>_H_`. Gate 7 of `scripts/check` checks guards instead.
- 2026-10-08: clang-tidy also disables `readability-identifier-length` (Google allows `i`, `dt`) and exempts snake_case methods from PascalCase so accessors like `is_open()` pass.
- 2026-10-08: Include order puts `<GLFW/glfw3.h>` before `<glad/gl.h>`, so CMake must define `GLFW_INCLUDE_NONE`.
- 2026-10-08: Dependencies pinned as release archives with SHA-256 hashes: GLFW 3.4 (as the spec fixes it, although 3.5.1 exists), Dear ImGui v1.92.9b, doctest v2.5.3. Vendored: glad2 2.0.8 (GL 3.3 core, no extensions) and stb_image v2.30.
- 2026-10-08: ASan + UBSan only run outside Windows: MinGW GCC has no sanitizer runtime. The `release` preset skips tests; `ci` builds them.
- 2026-10-08: Third-party include dirs are made SYSTEM via `INTERFACE_SYSTEM_INCLUDE_DIRECTORIES`, because the `SYSTEM` option of `FetchContent_Declare` needs CMake 3.25 and the floor is 3.24.
- 2026-10-08: The Phase 1 bootstrap lives in `src/main.cc` (RAII wrappers for GLFW, the window and ImGui) and moves into `App` in task 2.6. `csopesy_core` is added once there are sources besides `main.cc`.
- 2026-10-08: The ImGui demo window is behind the `CSOPESY_IMGUI_DEMO` CMake option (ON in the `debug` preset) and only compiles into Debug builds. `imgui.ini` is disabled (`IniFilename = nullptr`) so no layout state persists between runs.
- 2026-10-08: MinGW builds link libgcc/libstdc++ statically and copy `libwinpthread-1.dll` next to each exe (`csopesy_use_portable_runtime`). This also stops exes from loading a mismatched runtime from another MinGW on PATH, such as Git Bash's. A fully static link fails with the MinGW bundled with CLion.
- 2026-10-08: Tests are registered per test case with `doctest_discover_tests`, so `ctest -R <name>` runs a single case. The Phase 1 test is a smoke test of the harness; real tests start with `Clock` in task 2.1.
- 2026-10-08: `scripts/check.*` list files with `git ls-files --cached --others --exclude-standard`, so new files that are not yet committed are checked too. Gate 7 treats `src/data/`, `src/core/clock.*` and `src/core/state_machine.*` as testable logic.
- 2026-10-08: On Windows the check runs as `powershell -ExecutionPolicy Bypass -File scripts/check.ps1` instead of changing the machine's execution policy.
- 2026-10-08: `Clock` splits time-zone conversion (`ToLocalTime`, via `localtime_s` / `localtime_r`) from formatting (`FormatDateTime`, `std::put_time` with the classic locale). Formatting tests build `std::tm` fields directly, so they pass in any time zone; the injection test compares against the same conversion.
- 2026-10-08: `csopesy_core` starts with `src/core/clock.cc`; `src/` is its public include root, so project includes read `"core/clock.h"`.
- 2026-10-08: `StateMachine` holds state, timers and the PWR confirm step (`RequestShutdown` / `CancelShutdown` / `ConfirmShutdown`) but draws nothing; `App` picks what to render for each state, so the logic stays unit-testable. Default durations: BIOS 4 s, splash 2.5 s, shutdown 1 s.
- 2026-10-08: Fonts use the two fonts built into Dear ImGui (MIT): ProggyForever, the scalable default, for the shell and ProggyClean, a pixel font, for the boot screens. No font files or extra licenses to ship; a sans font such as Roboto can be added later as polish.
- 2026-10-08: `Theme` is in `csopesy_core`, which now links `imgui`. Its test runs on a bare ImGui context with no window or GPU.
- 2026-10-08: `AppWindow::Render` frames each app window: first-use size and a staggered offset, `ClampToWorkArea` keeps the title bar above the taskbar (and 64 px visible sideways), then the subclass's `Draw()`. The minimize button is drawn in the title bar beside ImGui's close button, after the contents, so moving the cursor there never disturbs the content layout.
- 2026-10-08: `IMGUI_DEFINE_MATH_OPERATORS` is defined on the `imgui` target so `ImVec2` arithmetic works everywhere.
- 2026-10-08: UI code is tested headless (`tests/imgui_test_support.h`): a bare ImGui context with `RendererHasTextures` set runs real frames with no window or GPU, and Debug builds keep IM_ASSERT on.
- 2026-10-08: A Roboto sans shell font is planned as optional Phase 4 polish (task 4.6).
- 2026-10-08: `WindowManager` tracks the active (front-most) app window itself instead of asking ImGui at click time, because clicking a taskbar button moves ImGui focus to the taskbar. The active window is set by the taskbar and by ImGui focus each frame, and dropped when it is minimized or closed. Clicking the desktop background does not clear it.
- 2026-10-08: `App` (`src/core/app.cc`) owns the frame loop; `main.cc` only creates it and returns `Run()`. GLFW, the window and ImGui are RAII locals of `Run()`, so PWR and the OS close button share one cleanup path. Until Phase 4, BIOS, Splash and Shutdown draw centered placeholder text, and any key or click skips the BIOS wait.
- 2026-10-08: The wallpaper gradient and the clock panel are drawn on ImGui's background draw list, which always renders under every window, so the layer order (wallpaper, clock, windows, taskbar) needs no z-order bookkeeping. `ClockPanelRect` anchors the panel to the viewport's top-right corner; screenshots confirmed it follows the corner on resize.
- 2026-10-08: The wallpaper is `assets/wallpaper.jpg`, a 1920x1080 abstract blue image generated for the project (no third-party license). `Texture` decodes it with stb_image from memory, so paths with non-ASCII characters work on Windows. It is drawn with `AddImage` on the background draw list, and `CoverUv` crops the overflowing axis so it covers the window without stretching. If the image is missing or can't be decoded, the gradient is drawn instead.
- 2026-10-08: Assets load relative to the executable (`core::ExecutableDirectory`: `GetModuleFileNameW`, `/proc/self/exe` or `_NSGetExecutablePath`), so the app finds them whatever the working directory. `App::Run` frees the wallpaper texture after the loop, while the GL context still exists.
- 2026-10-08: `.clang-format` gives every include category an explicit `SortPriority` so `<windows.h>` sorts before the Win32 sub-headers (`<libloaderapi.h>`, `<minwindef.h>`) that misc-include-cleaner asks us to include directly.
- 2026-10-08: The taskbar is a 56 px ImGui window placed from `MainViewportRect()` every frame (`TaskbarRect`). Focusing an app window brings it to the front, so the taskbar calls `BringWindowToDisplayFront` (from `imgui_internal.h`) each frame to stay on top. App windows get `WorkAreaAboveTaskbar`, so they are clamped above it.
- 2026-10-08: Flag combinations are built with `core::CombineFlags`, which ORs the flags as unsigned bits. ImGui's flag enums are signed ints, so `|` on them trips bugprone-signed-bitwise.
- 2026-10-08: Taskbar app buttons are `InvisibleButton`s with icons drawn on the draw list (folder, terminal prompt, activity line), so no icon image files are needed. The taskbar only forwards clicks to `WindowManager::ToggleFromTaskbar`. File Explorer, Terminal and Task Manager start as stub windows in task 3.3 so the open/minimize/restore flow works; each gets its real contents in its own task.
- 2026-10-08: Taskbar clicks are tested headless by feeding real mouse events (`AddMousePosEvent`, `AddMouseButtonEvent`) one per frame, so the tests go through ImGui's own hit-testing.
- 2026-10-08: Running indicators come from `IndicatorFor(WindowManager, AppWindow)`: hidden when closed, a short grey bar when open (minimized or behind), and a longer accent bar plus a faint button highlight when active. The draw code only reads this state, so the F08 rule is unit-tested without rendering.
- 2026-10-08: The system tray holds VOL and NET (placeholder buttons until their Phase 4 popups) and a red PWR button, right-aligned at fixed sizes (`TrayButtonRect`). PWR calls `StateMachine::RequestShutdown`; the taskbar opens the "Shut down CSOPESY OS?" modal while a shutdown is pending. Shut Down confirms and Cancel or Escape cancels. A real run confirmed Shut Down shows the shutdown screen and the process exits by itself with code 0.
- 2026-10-08: The taskbar only raises itself when no modal is open, so the PWR dialog stays in front and dims the taskbar like the rest of the desktop.
- 2026-10-08: `DummyProcessTable` holds 20 fixed rows (6 apps, 14 background processes, three of them Suspended) in one `constexpr` array. `ComputeTotals` is a free function over any span of rows, so the 100% cap is tested with rows built for that test. Memory % is measured against a fake 8 GB machine (`kSystemMemoryMb`). One instance is shared by the Task Manager and the Terminal's `ps`.
- 2026-10-08: The Task Manager draws its own header row instead of `TableHeadersRow`, so each header cell shows the column total above the name as Windows does (22% over CPU, 14% over Memory). The row is frozen with `TableSetupScrollFreeze`. Rows are grouped under "Apps (6)" and "Background processes (14)", numbers are right-aligned, and a click selects a row (`Selectable` spanning all columns). Cell text is formatted by pure functions (`FormatCpu`, `FormatMemory`, `FormatTotal`, `FormatGroupHeader`) with `std::format`, which are unit-tested.
- 2026-10-08: File Explorer keeps its placeholder listings (5 folders, 12 items in Documents) in `constexpr` arrays in `file_explorer.cc`, the only files F10 lists. The testable parts are pure functions in its header: `SortEntries`, `FolderHistory` (back/forward), `FormatSize` (thousands separators, blank for folders) and `FormatStatus`. Dates are stored as "YYYY-MM-DD HH:MM" so sorting the text sorts by date. Click selects one row, Ctrl+click adds or removes a row, and navigating clears the selection. The default size grew to 880x480 so the four columns fit.
- 2026-10-08: `TerminalCommands` turns one input line into output lines plus an effect (`kClearScreen` for `cls`, `kCloseWindow` for `exit`), so the window applies side effects and the parsing stays pure. Command names are case-insensitive as in cmd.exe. Date and time arrive as already-formatted strings in `CommandContext`, so `data/` does not depend on `core/Clock`. `ps` prints the shared `DummyProcessTable` as fixed-width text. `CommandHistory` skips blank input and repeats of the newest command, and adding a command restarts browsing at the newest.
- 2026-10-08: The Terminal window applies `TerminalCommands` results: it echoes `C:\CSOPESY>` plus the input, appends the output and a blank line, clears on `cls`, and on `exit` closes itself and resets to the banner so the next session starts fresh. The scrollback uses `ImGuiListClipper` and scrolls to the bottom after each command. Focus returns to the input after every command and when the window appears. Up and Down go through an `InputText` history callback to `CommandHistory`. `Clock` gained `FormatDate` and `FormatTime` for `date` and `time`.
- 2026-10-08: Typing, Enter and Up-arrow history are tested headless with `AddInputCharactersUTF8` and key events. In the real-window check, keys sent by `SendKeys` lack the extended-key flag (GLFW reads them as keypad keys), so the arrow test used `keybd_event` with the extended flag.
- 2026-10-09: The BIOS and splash screens draw on the background draw list from `time_in_state()`, so they fill the window at any size and animate without timers of their own. What is visible at a given time comes from pure, tested functions: `VisibleBiosLines` (one POST line every 0.12 s, with a memory test counting to 64000K over 1.5 s; the whole POST fits the 4 s BIOS), `LoadingText` (one to three dots every 0.4 s) and `SplashOpacity` (0.3 s fade-in). The BIOS text sits top-left with a blinking cursor; the splash centres the ASCII logo, the emulator name, the group credit and the loading line, padded so it does not shift as dots appear.
- 2026-10-09: At the team's request, the splash shows "CSOPESY - Section S01 - Group 12" instead of a generic author credit and tagline; member names live in `README.txt`.
- 2026-10-09: Taskbar buttons show tooltips with `SetItemTooltip`: the app's window title, "Volume: 70%" (or "muted"), "Network: CSOPESY-LAN" and "Shut down". VOL opens a popup with a volume slider and a Mute checkbox, and NET opens one showing "Connected: CSOPESY-LAN". The popups sit just above their tray button and close on a click outside or Escape. The volume state lives in `Taskbar`; nothing plays sound. The taskbar only re-raises itself when no popup is open, so popups stay in front.
- 2026-10-09: Task Manager CPU and Memory cells are shaded with `TableSetBgColor(CellBg)` from pale yellow to deep amber, blended over the dark table. `UsageHeat` scales a value against a full-scale point (10% CPU or 500 MB per process, 100% for the header totals), and `HeatColor` interpolates between two `Theme` colors. Both are pure and unit-tested.
- 2026-10-09: The BIOS screen shows a "Fun Fact:" footer, wrapped to the window width and anchored to the bottom margin. Facts live in `assets/fun_facts.txt` (one per line, `#` comments and blank lines skipped) so the team can edit them without touching code; `data::ParseFunFacts` and `PickFunFact` are pure and tested. Each launch picks one fact from a time-based seed; a built-in fact is used if the file is missing or empty.
- 2026-10-09: The desktop shows "CSOPESY OS v1.0 - System Online" with a green status dot in the top-left corner, in a panel styled like the clock (`DesktopLabelRect` mirrors `ClockPanelRect`).
- 2026-10-09: The shell font is Roboto Medium (`assets/fonts/Roboto-Medium.ttf`, Apache License 2.0, license text beside it), copied unmodified from the pinned Dear ImGui release so nothing new is downloaded. `Theme` reads it with `core::ReadFileBytes` and keeps the bytes alive for the atlas; if the file is missing, ProggyForever is used as before. The boot screens keep the ProggyClean pixel font.
